# 📘 Assignment: Games in Python

## 🎯 Objective

Create a fun and interactive Hangman game in Python that uses strings, loops, conditionals, and user input to make a complete game experience for a player.

## 📝 Tasks

### 🛠️ Build the Core Game Logic

#### Description
Create a Hangman game where a player guesses letters to reveal a hidden word before they run out of attempts.

#### Requirements
Completed program should:

- Randomly choose a word from a predefined list
- Display the hidden word as underscores and reveal letters as they are guessed correctly
- Accept one letter at a time as user input
- Track the number of incorrect guesses remaining
- Stop the game when the player wins or runs out of attempts
- Print a clear win or loss message at the end of the round

### 🛠️ Improve the Player Experience

#### Description
Add polish to the game so it feels user-friendly, readable, and easier to play.

#### Requirements
Completed program should:

- Show the player’s guessed letters and remaining attempts after each turn
- Handle invalid input such as empty entries or multiple characters
- Prevent duplicate guesses from counting as repeated mistakes
- Include a clear way to restart the game after the round ends
- Keep the program easy to understand and organized for future changes
